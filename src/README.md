# Northwind Orders API - RESTful Service

API REST construida con Express.js y PostgreSQL (Supabase) para la generación transaccional y consulta de órdenes de venta sobre el modelo de datos Northwind.

---

## 🛠️ Tecnologías Utilizadas

* **Runtime:** Node.js (ES Modules)
* **Framework:** Express.js
* **Base de Datos:** PostgreSQL / Supabase
* **Driver de Conexión:** `pg` (node-postgres con Connection Pooling)
* **Seguridad:** Helmet (cabeceras HTTP seguras) y CORS
* **Manejo de Entorno:** dotenv

---

## 📋 Requisitos Previos

* Node.js v18.0 o superior
* Instancia funcional de PostgreSQL con la base de datos Northwind importada
